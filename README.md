# Routing

A mobile-first web app for planning Trips and comparing Interesting Routes between Routing Places in the contiguous United States.

## Development

Install dependencies:

```sh
npm install
```

Run the app locally:

```sh
npm run dev
```

Run automated checks:

```sh
npm run check
```

Build for production:

```sh
npm run build
```
